# CARLOPHILLIPS site v1.2

Status: verified local candidate.

Baseline: local annotated tag `v1.1` at commit `c6753b5`.

## Purpose

v1.2 makes the active storefront token-led without redesigning the approved v1.1 runway and Signature Hoodie composition. It establishes one semantic presentation contract for the homepage, collection/shop, product detail, bag, checkout controls, media viewer, and private concept route.

## Included

- layered `--cp-*` primitives and semantic colour, typography, spacing, layout, effect, and motion roles in `app/globals.css`;
- reusable semantic classes for shells, sections, text tiers, labels, headings, actions, rules, cards, commerce states, variants, media, and private concepts;
- one shared `StorefrontHeader` for collection, bag, and product routes;
- refactored customer components with no raw black/white utilities, arbitrary hex colours, CSS colour literals, or one-off letter-spacing values;
- deterministic tests that enforce the semantic-token boundary across every active customer surface;
- the recovered noindex `/concept-preview` route, using the same tokens and explicit Draft-only campaign evidence.
- four concurrently created full-page concept screenshots, preserved as inspected QA evidence rather than silently discarded.

## Deliberately unchanged

- the v1.1 runway landing asset, copy hierarchy, `ONE` presentation, Signature Hoodie identity, media inventory, price, variants, release gates, and checkout policy;
- Shopify and provider integrations, product records, publishing state, billing, orders, and Production;
- `package.json` version, because these labels are local site milestones rather than npm package releases.
