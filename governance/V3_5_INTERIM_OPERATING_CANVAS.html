Rule 1 — No agent-to-agent communication. None.

Pushpa and Aarti never talk to each other, and never to Watchdog. Direct agent chatter burns tokens restating context that already exists on disk, and every restatement is a chance for facts to drift. Sushma is the only hub. Handoff happens by changing a file and requesting a state change — never by conversation.

6The three-line signal

Only the role currently assigned owes a signal. An unassigned role sends nothing and is not treated as stalled. IN_PROGRESS alone is not a useful return.

ITEM: <item-id> | RESULT: READY_FOR_<STATE> / BLOCKED / FAILED / DIRECTION_CHECK EVIDENCE: <artifact, commit, test, deployment, trace, or finding> NEXT: <requested transition> | OWNER: <next owner> | RESUME: <trigger or immediate>

Written to state/signals/{YYYY-MM-DD}/{timestamp}-{role}-{item}.md. The signal is not canonical state — Sushma verifies the evidence, accepts or rejects, then updates NOW and BOARD.

⚠️

Truth and freshness rules

Every tile shows source and last refresh. The dashboard must distinguish not configured, unavailable, stale, failing and healthy — they are not the same thing. No green status may rely on an agent's self-report when repository or environment evidence should exist.

9Enforced rules

Sushma checks all eight on every activation. A violation is a P2 by default, P1 once it has cost delivery time.

1 · No agent-to-agent comms

Sushma is the only hub. No exceptions.

Chatter costs tokens and creates two versions of the truth.

2 · Dispatch is a pointer

Name the files to read. Never paste their contents into a prompt.

The board is the memory, not the prompt.

3 · Handoff by file and state

Change a file, request a state change. Sushma verifies and moves the Board.

Aarti learns of Pushpa's work from the item file, never from Pushpa.

4 · Every state change writes an event

state/events.jsonl, append-only, by the actor who caused it.

A transition with no event did not happen.

5 · Log the decision before asking

D-number with QUESTION / OPTIONS / IMPACT / RECOMMENDATION, then ask.

A decision raised in conversation and not logged does not exist.

6 · Bare PASS prohibited

Carry the command or file:line. Separate verified fact from assumption.

"Not examined" may never be graded "fine".

7 · Build in an isolated worktree

Never on a shared branch. Sushma deletes it at release.

Isolation is what makes a rollback cheap.

8 · Delivery is proven by a remote SHA

Never grade shipped on a local commit.

Four commits once sat in a clone whose origin was a folder.
